Poznámky k provozu
Souřadnicové rámce: geometrie letadlo↔pozorovatel se počítá nad elipsoidem WGS-84. ADS-B výška alt_geom (GNSS, nad elipsoidem) má přednost; alt_baro slouží jen jako fallback s korekcí o geoid a širší nejistotou (⚠ v detailu řádku). Pole „Geoid N" převádí nadmořské výšky na elipsoidální (ČR ≈ +44,5 m).

Efemerida: Měsíc dle zkrácené řady Meeus (kap. 47, 60+60 členů) + nutace + ΔT + vektorová topocentrická paralaxa; Slunce dle Meeus kap. 25 (~0,01°). Při startu proběhne křížová kontrola proti nezávislému Schlyterovu modelu — výsledek ukazuje chip EFEM ve stavové liště. Doporučené jednorázové ověření: JPL Horizons → Observer Table (Moon, tvoje souřadnice) a porovnání s readouty Az/El zde.

Predikce: hrubý sken → zlatý řez na ~0,05 s → kontaktní časy vstup/výstup, trvání tranzitu a tětiva. Nejistota σ vychází ze stáří fixace, stability kurzu a zdroje výšky → P(zásah). Letadla v zatáčce (⟳) se propagují po oblouku podle odhadnuté úhlové rychlosti z historie fixací.

Data: adsb.lol / adsb.fi přes vlastní proxy /api/aircraft (veřejná API neposílají CORS), s automatickým failoverem a kotvením času na serverové razítko. Při události < 150 s se dotazování samo zrychlí (⚡). Limit veřejných API ~1 dotaz/s nepřekračuj. Data © přispěvatelé adsb.lol (ODbL) a adsb.fi.

Nasazení: index.html + serverless funkce api/aircraft.js (Vercel). Z disku (file://) funguje jen SIMULACE. Notifikace, GPS, kompas, Wake Lock a tlačítko Sdílet vyžadují https. Slunce vždy jen s certifikovaným filtrem.
